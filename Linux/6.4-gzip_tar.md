# Compressing and Archiving Files with `gzip` and `tar`

## Learning Objectives

By the end of this lesson, students will be able to:

* Explain the difference between compression and archiving.
* Compress and decompress individual files with `gzip` and `gunzip`.
* Create, list, and extract `tar` archives.
* Create and extract compressed `tar.gz` archives.
* Choose appropriate options when working with archives.

---

## Compression versus Archiving

Compression reduces the size of a file.

Archiving combines multiple files and directories into a single file.

| Command | Primary purpose |
| --- | --- |
| `gzip` | Compress or decompress a file |
| `tar` | Create or extract an archive |

The commands are often used together. `tar` creates one archive containing
many files, and `gzip` compresses that archive.

---

## Using `gzip`

`gzip` compresses a file and replaces it with a file ending in `.gz`.

```bash
gzip notes.txt
```

The original `notes.txt` file is removed and replaced by `notes.txt.gz`.

To keep the original file, use `-k`:

```bash
gzip -k notes.txt
```

This creates `notes.txt.gz` while leaving `notes.txt` in place.

### Useful `gzip` options

| Option | Description | Example |
| --- | --- | --- |
| `-k` | Keep the original file | `gzip -k notes.txt` |
| `-d` | Decompress a file | `gzip -d notes.txt.gz` |
| `-c` | Write compressed output to standard output | `gzip -c notes.txt > notes.txt.gz` |
| `-t` | Test whether an archive is valid | `gzip -t notes.txt.gz` |
| `-l` | Display compression information | `gzip -l notes.txt.gz` |
| `-1` | Use faster compression | `gzip -1 notes.txt` |
| `-9` | Use maximum compression | `gzip -9 notes.txt` |

### Decompressing a `.gz` file

The `gunzip` command decompresses a gzip file:

```bash
gunzip notes.txt.gz
```

You can also use `gzip -d`:

```bash
gzip -d notes.txt.gz
```

Both commands replace `notes.txt.gz` with `notes.txt`.

### Viewing compressed content

`zcat` displays the contents of a compressed text file without creating a
decompressed copy:

```bash
zcat notes.txt.gz
```

---

## Using `tar`

`tar` stands for tape archive. It creates one archive that contains files,
directories, and their directory structure.

### Create an archive

```bash
tar -cvf project.tar project/
```

| Option | Purpose |
| --- | --- |
| `-c` | Create an archive |
| `-v` | Verbosely display files being added |
| `-f` | Specify the archive file name |

You can include multiple files and directories in one command:

```bash
tar -cvf backup.tar notes.txt scripts/ images/
```

### List archive contents

List files without extracting them:

```bash
tar -tvf project.tar
```

### Extract an archive

Extract an archive into the current directory:

```bash
tar -xvf project.tar
```

| Option | Purpose |
| --- | --- |
| `-x` | Extract an archive |
| `-v` | Verbosely display extracted files |
| `-f` | Specify the archive file name |

Extract an archive into a specific directory:

```bash
mkdir restore
tar -xvf project.tar -C restore
```

---

## Using `tar` with `gzip`

A compressed tar archive usually ends in `.tar.gz` or `.tgz`.

### Create a compressed archive

```bash
tar -czvf project.tar.gz project/
```

The `-z` option tells `tar` to use `gzip` compression.

### Extract a compressed archive

```bash
tar -xzvf project.tar.gz
```

### Extract into another directory

```bash
mkdir restore
tar -xzvf project.tar.gz -C restore
```

### List a compressed archive

```bash
tar -tzvf project.tar.gz
```

The common `tar` option combinations are:

* `-cvf archive.tar files` - create a tar archive
* `-czvf archive.tar.gz files` - create a gzip-compressed tar archive
* `-tvf archive.tar` - list tar archive contents
* `-tzvf archive.tar.gz` - list compressed archive contents
* `-xvf archive.tar` - extract a tar archive
* `-xzvf archive.tar.gz` - extract a gzip-compressed tar archive

---

## Safety Tips

* List archive contents before extracting unfamiliar archives.
* Be careful when extracting archives that contain absolute paths or paths
  beginning with `../`.
* Use `-C` to extract files into a known directory.
* Verify available disk space when extracting large archives.

## Practice Exercises

1. Compress `notes.txt` while keeping the original file.

   ```bash
   gzip -k notes.txt
   ```

2. Decompress `notes.txt.gz`.

   ```bash
   gunzip notes.txt.gz
   ```

3. Create an archive named `project.tar` containing the `project` directory.

   ```bash
   tar -cvf project.tar project/
   ```

4. List the contents of `project.tar`.

   ```bash
   tar -tvf project.tar
   ```

5. Extract `project.tar` into the current directory.

   ```bash
   tar -xvf project.tar
   ```

6. Create a gzip-compressed archive named `project.tar.gz`.

   ```bash
   tar -czvf project.tar.gz project/
   ```

7. List the contents of `project.tar.gz`.

   ```bash
   tar -tzvf project.tar.gz
   ```

8. Extract `project.tar.gz` into a new directory named `restore`.

   ```bash
   mkdir restore
   tar -xzvf project.tar.gz -C restore
   ```

---

## Key Takeaways

* Use `gzip` to compress individual files.
* Use `gunzip` or `gzip -d` to decompress individual files.
* Use `tar` to combine files and directories into an archive.
* Use `tar -z` when creating or extracting gzip-compressed tar archives.
* Use `tar -t` to inspect an archive before extracting it.
