Here’s a **classroom-ready exercise** I use that consistently helps students *feel* the difference instead of just memorizing it.

***

# 🧪 Classroom Exercise: “Modify or Reassign?”

## 🎯 Learning Goal

Students will learn:

* Difference between **modifying vs reassigning**
* How Python passes objects
* Why mutable vs immutable matters

***

# 📝 Part 1: Predict the Output

Tell students:

> “Don’t run the code yet. First, predict what happens.”

***

### 🔹 Example A (Immutable)

```python
def func(x):
    x = x + 5

a = 10
func(a)
print(a)
```

👉 Ask:

* What will `print(a)` output?

***

### 🔹 Example B (Mutable – modifying)

```python
def func(lst):
    lst.append(100)

numbers = [1, 2, 3]
func(numbers)
print(numbers)
```

👉 Ask:

* What will `print(numbers)` output?

***

### 🔹 Example C (Mutable – reassigning)

```python
def func(lst):
    lst = [9, 9, 9]

numbers = [1, 2, 3]
func(numbers)
print(numbers)
```

👉 Ask:

* What will `print(numbers)` output?

***

### 🔹 Example D (Tricky!)

```python
def func(lst):
    lst = lst + [4]

numbers = [1, 2, 3]
func(numbers)
print(numbers)
```

👉 Ask:

* Is this modifying or reassigning?

***

# ✅ Part 2: Run and Compare

After students commit to answers, run the code together.

***

# 🧠 Answer Key

### A:

```
10
```

✅ Immutable → new object created → no change

***

### B:

```
[1, 2, 3, 100]
```

✅ Modified the same list → change persists

***

### C:

```
[1, 2, 3]
```

❌ Reassigned → original unchanged

***

### D:

```
[1, 2, 3]
```

❌ `lst + [4]` creates a new list → reassignment!

***

# 💡 Teaching Moment (Pause Here)

Ask:

> “Why does `.append()` behave differently than `+`?”

Answer:

* `.append()` → modifies the same object
* `+` → creates a *new* object

***

# 🔄 Part 3: Student Challenge

Have students write a function:

### Prompt:

> Write a function that **adds an item to a list**, but does NOT modify the original list.

***

### Expected Solution:

```python
def add_item(lst):
    return lst + [99]

a = [1, 2, 3]
b = add_item(a)

print(a)  # unchanged
print(b)  # new list
```

***

# 🔥 Part 4: Extension (Advanced Insight)

Ask:

> “How would you modify the original list on purpose?”

```python
def add_item(lst):
    lst.append(99)
```

***

# 🎓 Wrap-Up Rule (Have Students Write This Down)

> ✅ “If you modify the object, changes stick.”  
> ❌ “If you reassign the variable, they don’t.”

***

# 🧑‍🏫 Instructor Tip

A great quick check question:

> “Does this line create a new object or change an existing one?”

Examples:

* `lst.append(1)` ✅ modify
* `lst = lst + [1]` ❌ new object
* `x += 1` ❌ new object (for ints)
