# Using `top` for Process Monitoring

## Learning Objectives

By the end of this lesson, students will be able to:

* Start and exit the interactive `top` command.
* Interpret CPU, memory, load, and process information.
* Sort processes by CPU or memory usage.
* Filter, kill, and renice processes from `top`.
* Use common `top` command-line options.

---

## What Is `top`?

`top` provides a continuously updating view of running processes, CPU usage,
memory usage, system load, uptime, and other system metrics.

Start `top`:

```bash
top
```

Press `q` to exit.

---

## Understanding the Display

`top` has two main sections:

1. A system summary at the top.
2. A process table below the summary.

### System Summary

Common fields include:

| Field | Description |
| --- | --- |
| `top` and uptime | Current time and how long the system has been running |
| `tasks` | Total, running, sleeping, stopped, and zombie processes |
| `%Cpu(s)` | CPU usage across user, system, idle, and wait categories |
| `MiB Mem` or `KiB Mem` | Physical memory usage |
| `MiB Swap` or `KiB Swap` | Swap memory usage |
| `load average` | Average number of runnable processes over 1, 5, and 15 minutes |

The load average should be interpreted in relation to the number of CPU
cores. A load average equal to the core count means the system is fully
utilized; sustained values above the core count may indicate CPU contention.

### Process Table

Common columns include:

| Column | Description |
| --- | --- |
| `PID` | Process ID |
| `USER` | User who owns the process |
| `PR` and `NI` | Process priority and niceness |
| `VIRT`, `RES`, and `SHR` | Virtual, resident, and shared memory usage |
| `%CPU` | CPU percentage used by the process |
| `%MEM` | Percentage of physical memory used by the process |
| `TIME+` | Total CPU time used by the process |
| `COMMAND` | Process command or program name |

## Interactively Control `top`

While `top` is running, use the following keys:

| Key | Action |
| --- | --- |
| `q` | Quit `top` |
| `h` or `?` | Display help |
| `P` | Sort by CPU usage |
| `M` | Sort by memory usage |
| `N` | Sort by PID |
| `T` | Sort by elapsed or CPU time |
| `k` | Prompt for a PID to kill |
| `r` | Prompt for a PID and change its niceness |
| `u` | Display processes for a selected user |
| `z` | Toggle color |
| `1` | Expand or collapse individual CPU cores |
| `Space` | Refresh immediately |

Press the key without first pressing Enter.

---

## Sort by Resource Usage

By default, many versions of `top` begin by sorting processes by CPU usage.
Use:

* `P` to sort by CPU usage.
* `M` to sort by memory usage.

To reverse the sort order, press `R`.

---

## Change Process Priority

The nice value affects process scheduling priority. Higher nice values are
lower priority, while lower or negative values are higher priority.

To change a process priority interactively:

1. Start `top`.
2. Press `r`.
3. Enter the PID.
4. Enter a new niceness value.

Changing to a higher nice value:

```text
PID to renice [default pid = ...]: 1234
Renice PID 1234 to value: 10
```

Changing priority usually requires appropriate permissions. Only use `sudo`
with `top` when administrative changes are required:

```bash
sudo top
```

---

## Kill a Process

Press `k` in `top`, enter a PID, and choose a signal:

```text
PID to kill: 1234
Kill PID 1234 with signal [15]: 15
```

Signal `15` requests a graceful termination. Signal `9` forcefully terminates
a process and should be used only when it does not stop normally.

Use caution because killing a process may interrupt an application or cause
data loss.

## Useful Command-Line Options

```bash
top -d 5
```

Refresh every 5 seconds.

```bash
top -u student
```

Display only processes owned by the `student` user.

```bash
top -p 1234,5678
```

Monitor only the specified PIDs.

```bash
top -n 3
```

Update three times and then exit.

```bash
top -b -n 1
```

Produce a single non-interactive snapshot suitable for scripts or logging.

## Troubleshooting Example

1. Start `top`.

   ```bash
   top
   ```

2. Press `P` to sort by CPU.
3. Identify an unexpected high-CPU PID.
4. Press `1` to review individual CPU core usage.
5. Inspect the process using another terminal:

   ```bash
   ps -fp PID
   ```

6. Stop the process with `kill` only if appropriate:

   ```bash
   kill PID
   ```

## Practice Exercises

1. Start `top`.
2. Press `q` to exit.
3. Sort processes by memory usage with `M`.
4. Sort processes by CPU usage with `P`.
5. Toggle individual CPU display with `1`.
6. Create a one-time batch-mode snapshot:

   ```bash
   top -b -n 1
   ```

7. View only processes owned by your current user:

   ```bash
   top -u "$USER"
   ```

8. Run a safe process lookup using the process ID of a running process:

   ```bash
   ps -fp PID
   ```

---

## Key Takeaways

* `top` provides a real-time view of system and process activity.
* Use `P` to sort by CPU and `M` to sort by memory.
* `load average` shows system demand over time.
* Use `k` to terminate a process and `r` to change its nice value.
* Press `q` to quit.
* Use batch mode when collecting snapshots for scripts or logs.
