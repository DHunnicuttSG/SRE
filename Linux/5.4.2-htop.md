# Using `htop` for Interactive Process Monitoring

## Learning Objectives

By the end of this lesson, students will be able to:

* Install or start `htop` when it is available.
* Navigate the `htop` interface.
* Interpret CPU, memory, and process information.
* Search, filter, sort, and tag processes.
* Set process priority or terminate processes safely.
* Explain when `htop` is preferred over `top`.

---

## What Is `htop`?

`htop` is an enhanced interactive process viewer. It is similar to `top`, but
provides:

* A colorized system summary.
* Per-CPU usage bars.
* Easier keyboard navigation.
* Mouse support in many terminal environments.
* Interactive process filtering, sorting, and killing.
* Tree and search views.

Start `htop`:

```bash
htop
```

Press `q` or use `F10` to exit.

---

## Installing `htop`

Availability depends on the Linux distribution:

### Debian or Ubuntu

```bash
sudo apt update
sudo apt install htop
```

### Red Hat, CentOS Stream, or Rocky Linux

```bash
sudo dnf install htop
```

### Fedora

```bash
sudo dnf install htop
```

If the package manager indicates that `htop` is unavailable, enable the
distribution's appropriate package repository or use `top`.

## Understanding the Interface

### Upper Summary Area

The upper area commonly displays:

* CPU usage bars, usually one per core or thread.
* Memory usage.
* Swap usage.
* Tasks, load average, and uptime.

Long bars or high percentages indicate greater resource use.

### Process Area

Common process columns include:

| Column | Description |
| --- | --- |
| `PID` | Process ID |
| `USER` | User who owns the process |
| `PRI` | Kernel priority |
| `NI` | Nice value |
| `VIRT`, `RES`, and `SHR` | Virtual, resident, and shared memory |
| `CPU%` | CPU usage percentage |
| `MEM%` | Memory usage percentage |
| `TIME+` | Accumulated CPU time |
| `Command` | Process command and arguments |

---

## Common Navigation Keys

| Key | Action |
| --- | --- |
| Arrow keys | Move through the process list |
| `PgUp` / `PgDn` | Move one screen up or down |
| `Home` / `End` | Move to the first or last process |
| `F3` or `/` | Search by process name |
| `F4` or `\` | Filter the process list |
| `F5` | Toggle tree view |
| `F6` | Choose the sort column |
| `F9` | Send a signal or kill a process |
| `F7` | Decrease the nice value and increase priority |
| `F8` | Increase the nice value and decrease priority |
| `F10` or `q` | Quit |

Exact function-key behavior can vary by terminal or distribution.

---

## Search for a Process

Press `F3` and enter part of the process command or name.

For example:

```text
python
```

Use the arrow keys or press `F3` repeatedly to move through matches.
Press `Esc` to leave search mode.

---

## Filter Processes

Press `F4`, then enter text used to filter the process list.

For example:

```text
nginx
```

Only processes matching the filter remain visible. Clear the filter to view
all processes again.

---

## Sort and View Processes in a Tree

Press `F6` to choose a sort column such as:

* `PID`
* `CPU%`
* `MEM%`
* `TIME+`
* `USER`

Press `F5` to display the process hierarchy. This view is useful for seeing
which parent process launched child processes.

---

## Change Process Priority

Select a process using the arrow keys.

* Press `F7` to increase priority.
* Press `F8` to decrease priority.

These actions change the process nice value:

* Lower nice values have higher priority.
* Higher nice values have lower priority.

Administrative permissions are required for some priority changes.

---

## Terminate a Process

1. Select the process.
2. Press `F9`.
3. Choose a signal.
4. Confirm the action.

Common signals include:

| Signal | Description |
| --- | --- |
| `15` - SIGTERM | Request a normal termination |
| `9` - SIGKILL | Forcefully terminate the process |

Use `SIGTERM` first. Use `SIGKILL` only when the process does not stop
normally, because unsaved data may be lost.

---

## Compare `top` and `htop`

| Feature | `top` | `htop` |
| --- | --- | --- |
| Usually preinstalled | More common | Often requires installation |
| Interface | Text based | Colorized and interactive |
| Process tree | Limited or requires options | Built-in toggle with `F5` |
| Filtering | Limited | Easy with `F4` |
| Searching | Limited | Easy with `F3` |
| Per-CPU bars | Often available | Usually prominent |
| Scripting | Supports batch mode | Primarily interactive |

Use `top` for default installations or scripts. Use `htop` when available
for interactive investigation.

---

## Troubleshooting Workflow

1. Start `htop`:

   ```bash
   htop
   ```

2. Look for high CPU or memory usage in the upper summary.
3. Press `F6` and sort by `CPU%` or `MEM%`.
4. Search for a process or filter the list.
5. Press `F5` to inspect its process tree.
6. Inspect details for the process in another terminal:

   ```bash
   ps -fp PID
   ```

7. Change priority or terminate the process only if authorized and appropriate.

---

## Key Takeaways

* `htop` is an interactive process monitor with an enhanced interface.
* Use `F3` to search and `F4` to filter.
* Use `F5` for tree view and `F6` to select a sort column.
* Use `F7` and `F8` to adjust process priority.
* Use `F9` to send signals, beginning with `SIGTERM`.
* Use `q` or `F10` to exit.
