# Answer Key

## Exercise 1 Solution

### Given

```text
IP Address: 192.168.7.45
Mask:       /23
```

### Step 1: Find the Block Size

```text
256 - 254 = 2
```

Subnet increments:

```text
0, 2, 4, 6, 8, 10...
```

### Step 2: Find the Correct Range

Third octet:

```text
7
```

Falls within:

```text
6 - 7
```

### Answer

```text
Network Address:   192.168.6.0
Broadcast Address: 192.168.7.255
First Host:        192.168.6.1
Last Host:         192.168.7.254
Usable Hosts:      510
```

## Exercise 3 Solution

### Given

```text
192.168.0.0/24 → /26
```

### Step 1: Borrowed Bits

```text
26 - 24 = 2
```

### Step 2: Number of Subnets

```text
2² = 4 subnets
```

### Step 3: Subnet Addresses

```text
192.168.0.0/26
192.168.0.64/26
192.168.0.128/26
192.168.0.192/26
```

### Step 4: Hosts Per Subnet

```text
2^(32 - 26) - 2

2^6 - 2

64 - 2

62 usable hosts
```

# Quick Subnetting Reference

## Step 1: Find the Interesting Octet

The interesting octet is the first octet that is neither:

```text
255
```

nor

```text
0
```

Example:

```text
255.255.248.0
        ↑
Interesting Octet
```

---

## Step 2: Calculate the Block Size

```text
Block Size = 256 - Mask Value
```

Examples:

```text
256 - 254 = 2
256 - 252 = 4
256 - 248 = 8
256 - 240 = 16
```

---

## Step 3: Build Subnet Boundaries

```text
Block Size 1:   0,1,2,3...
Block Size 2:   0,2,4,6...
Block Size 4:   0,4,8,12...
Block Size 8:   0,8,16,24...
Block Size 16:  0,16,32,48...
Block Size 32:  0,32,64,96...
Block Size 64:  0,64,128,192...
Block Size 128: 0,128
```

---

## Step 4: Determine the Correct Subnet

Find which subnet range contains the IP address value in the interesting octet.

---

## Step 5: Calculate Hosts

```text
Hosts = 2^(Host Bits) - 2
```

Where:

```text
Host Bits = 32 - CIDR
```

### Example

```text
/23

32 - 23 = 9

2^9 - 2 = 510 Hosts
```
