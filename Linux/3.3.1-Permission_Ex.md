# Linux File Permissions Exercises

These exercises provide hands-on practice with Linux file and directory permissions using `chmod`, `chown`, `chgrp`, and `umask`.

---

# Exercise 1: Read-Only File

## Objective
Make a file readable by everyone but writable only by the owner.

## Tasks
1. Create a file named `report.txt`.
2. Set permissions so:
   - Owner: Read, Write
   - Group: Read
   - Others: Read
3. Verify the permissions.

# Exercise 9: Configure Default Permissions with umask

## Objective
Understand how `umask` affects newly created files and directories.

## Tasks
1. Display the current umask value.
2. Set the umask to `027`.
3. Create a new file and directory.
4. Review the resulting permissions.

## Questions

1. Why is the file not executable?
2. Which permissions were removed by the `umask` value?
3. How would the permissions differ if the umask were `022`?

# Exercise 10: Permission Troubleshooting

## Objective
Diagnose and fix a permission problem.

## Scenario

A user cannot execute the script below:

```text

```

## Tasks
1. Identify why the script cannot be executed.
2. Grant only the minimum permissions needed for the owner to execute the file.
3. Verify the result.

## Exercise 9

### Commands

```bash
umask
umask 027

touch testfile
mkdir testdir

ls -l testfile
ls -ld testdir
```

### Answers

1. Files are created without execute permissions by default.
2. `027` removes:
   - Group write (`w`)
   - All permissions for others (`rwx`)
3. With `022`:
   - New file: `644`
   - New directory: `755`

---

## Exercise 10

### Commands

```bash
chmod u+x backup.sh
ls -l backup.sh
```

### Expected Result

```text
-rwxr--r--
```

### Explanation

The file lacked execute (`x`) permissions. Adding execute permission for the owner is the minimum change required.
