### Get all contacts
curl -X GET http://localhost:5000/api/contacts

### Get one contact
curl -X GET http://localhost:5000/api/contacts/1

### Create contact
curl -X POST http://localhost:5000/api/contacts \
-H "Content-Type: application/json" \
-d '{"name":"Jane Doe","phone":"5551234567","email":"jane@example.com"}'

### Update a contact
curl -X PUT http://localhost:5000/api/contacts/1 \
-H "Content-Type: application/json" \
-d '{"name":"John Updated","phone":"1112223333","email":"john.updated@example.com"}'

### Delete a contact
curl -X DELETE http://localhost:5000/api/contacts/1
