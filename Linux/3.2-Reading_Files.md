## Linux File Viewing and Searching Commands

Linux provides several commands to view and search through files directly from the terminal. These are essential for working with logs, scripts, and text files.

---

### 1. `cat` – Concatenate and Display Files

The `cat` command is used to display the contents of a file, combine multiple files, or create new ones.

* **Usage:**

  ```
  cat filename
  ```
* **Examples:**

  ```
  cat notes.txt                  # show file contents
  cat file1.txt file2.txt > all.txt  # combine files into one
  ```

---

### 2. `head` – Show the Beginning of a File

The `head` command shows the first 10 lines of a file by default.

* **Usage:**

  ```
  head filename
  ```
* **Options:**

  * `head -n 20 filename` → show first 20 lines
  * `head -c 50 filename` → show first 50 characters

---

### 3. `tail` – Show the End of a File

The `tail` command shows the last 10 lines of a file by default.

* **Usage:**

  ```
  tail filename
  ```
* **Options:**

  * `tail -n 20 filename` → show last 20 lines
  * `tail -f filename` → follow a file live (useful for logs)

---

### 4. `less` and `more` – Paginated File Viewing

The `less` and `more` commands display long files one screen at a time.
`less` is usually preferred because it supports forward and backward
navigation, searching, and displaying piped command output.

#### Viewing a file with `less`

```bash
less filename
```

For example:

```bash
less /var/log/syslog
```

This opens the file in `less`. The file remains interactive until you press
`q` to quit and return to the shell prompt.

#### Basic navigation

| Key | Action |
| --- | --- |
| `Space` or `f` | Move forward one screen |
| `b` | Move backward one screen |
| `Enter` | Move down one line |
| `j` | Move down one line |
| `k` | Move up one line |
| `g` | Go to the beginning of the file |
| `G` | Go to the end of the file |
| `q` | Quit `less` |

You can also use the up and down arrow keys.

#### Searching within `less`

To search forward from the current position:

```text
/word
```

Press `Enter` to run the search. To search backward:

```text
?word
```

After running a search:

* Press `n` to move to the next match.
* Press `N` to move to the previous match.
* Press `Esc` followed by `u` to turn off highlighting in some `less` builds.

To search only for an exact capitalization, use a capital letter in the
search term. To perform a case-insensitive search, start `less` with `-i`:

```bash
less -i filename
```

For example, searching for `error` in case-insensitive mode will match
`error`, `Error`, and `ERROR`.

#### Common `less` options

| Option | Description | Example |
| --- | --- | --- |
| `-N` | Display line numbers | `less -N logfile.txt` |
| `-S` | Do not wrap long lines | `less -S report.csv` |
| `-i` | Ignore case during searches | `less -i logfile.txt` |
| `-X` | Keep screen contents after exiting | `less -X filename` |
| `+F` | Start in follow mode | `less +F logfile.txt` |

Use arrow keys or the `h`, `j`, `k`, and `l` keys when navigating through
long or wide output. Press `q` to leave follow mode when tracking a growing
log file:

```bash
less +F /var/log/syslog
```

#### Searching for line numbers

The `-N` option adds line numbers on the left side of the screen:

```bash
less -N /var/log/syslog
```

You can also go directly to a line number when opening a file:

```bash
less +125 filename
```

#### Piping output into `less`

`less` can read output from another command through a pipe:

```bash
history | less
ps aux | less
grep -i "error" /var/log/syslog | less
```

This is especially useful when command output is too long to fit on one
screen. You can navigate and search the output just as you would a file.

#### `less` versus `more`

The `more` command moves forward through a file, usually one screen at a
time. Press `Space` to continue and `q` to quit:

```bash
more filename
```

`less` supports more navigation and searching controls, so it is preferred
for reviewing large files and command output.

---

### 5. `grep` – Search for Text

The `grep` command searches for patterns inside files and prints matching lines.

* **Usage:**

  ```
  grep "pattern" filename
  ```
* **Examples:**

  ```
  grep "error" logfile.txt          # find lines containing 'error'
  grep -i "warning" logfile.txt     # case-insensitive search
  grep -r "TODO" ~/projects         # search recursively in a directory
  grep -n "main" program.c          # show line numbers with matches
  ```

   ```

   ```

   ```
   head -n 5 report.txt
   ```

3. Show the last 20 lines of `system.log`.

   ```
   tail -n 20 system.log
   ```

4. View `bigfile.txt` one page at a time.

   ```
   less bigfile.txt
   ```


---

**Key Takeaway:**

* Use `cat` for quick output.
* Use `head`/`tail` to peek at the beginning or end.
* Use `less`/`more` to scroll through large files.
* Use `grep` to search inside files.
